How a config file becomes a settings panel

# comment→row description
key:→labeled row + icon
true / false→switch
one of …→segmented picker
[a, b]→tag chips
1–5→slider
123→stepper
nested:→drill-in section

The dotted marks are descriptions pulled from the file's comments — fig preserves them, so the config's own notes become the UI's help text. Icons, section titles, and enum choices come from a schema/config layer; everything else is inferred from the value's shape.
